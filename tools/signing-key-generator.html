ساخت کلید امضای مینی زکا سیتی

این ابزار کلید خصوصی و گواهی امضای اندروید را می‌سازد و تطابق آن‌ها را قبل از دانلود بررسی می‌کند. فایل PKCS#12 در GitHub Actions ساخته می‌شود تا با Java سازگار باشد.

مهم: رمز را خودت انتخاب کن و در جای امن نگه دار. فایل متنی و رمز را گم نکن؛ بدون آن‌ها انتشار آپدیت با امضای قبلی ممکن نیست. رمز را در چت یا کد عمومی GitHub نفرست.
بعد از وارد کردن رمز، روی دکمه ساخت بزن.

کلید در مرورگر همین دستگاه ساخته می‌شود و این صفحه آن را به هیچ سروری ارسال نمی‌کند. برای ساخت فایل از کتابخانه رمزنگاری node-forge نسخه 1.3.1 استفاده می‌شود که از jsDelivr بارگیری می‌شود؛ بنابراین هنگام ساخت، اتصال اینترنت لازم است.
